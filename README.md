# Для Варі ❤️

Оновлений birthday quest: чотири зашифровані рівні в існуючому varya-day. Кожен QR містить окремий ключ у URL fragment; ключ не надсилається серверу. QR й повні посилання зберігай приватно — не коміть їх у публічний репозиторій.

Level 1: 1370 днів. Level 2: «і я скажу», потім відео. Level 3: «Куди?» та boarding pass на 18 OCT 2026, 16:30, координати 35.3222446,25.3918038, Navigate. Level 4: Варя/Пупсік/я/я сама/це я, побажання та PDF-подарунок. Перевірка ігнорує регістр, пробіли й пунктуацію.

Сторінки незалежні. Перезавантаження повертає питання. Підтримано reduced motion. Це гра, а не захист від людини, яка вже має QR.

## Публікація

Settings → Pages → Deploy from a branch → main → / (root).

## Відео та подарунок

На Level 2 та Level 4 спочатку питання. Лише правильна відповідь відкриває побажання й запускає завантаження та розшифрування медіа. До відповіді немає доступних медіапосилань чи підключеного плеєра. Після відповіді Level 2 має кнопки «Відкрити відео» (плеєр на сторінці) та «Завантажити відео». Level 4 має кнопки «Відкрити подарунок» та «Завантажити подарунок PDF». Зображення та вбудований перегляд квитка видалені.

Відео Varya.mp4: мобільна версія H.264/AAC 540×960, близько 14 MB. Подарунок — оригінальний PDF. Медіафайли захищені AES-GCM ключами QR. Це сценарій гри, не серверна авторизація; власник QR-ключа може розшифрувати файл самостійно. Ключі й розшифровані файли не публікуються в репозиторії. QR залишились незмінними.

## Друк

Приватний комплект містить SVG і PNG високої якості та qr-print.html для A4. Друкуй у масштабі 100%, не обрізай біле поле. Перевір камерою телефона перед врученням.
