# Для Варі ❤️

Оновлений birthday quest: чотири зашифровані рівні в існуючому varya-day. Кожен QR містить окремий ключ у URL fragment; ключ не надсилається серверу. QR й повні посилання зберігай приватно — не коміть їх у публічний репозиторій.

Level 1: 1370 днів. Level 2: «і я скажу». Level 3: «Куди?» та boarding pass на 18 OCT 2026, 16:30, координати 35.3222446,25.3918038, Navigate. Level 4: Варя/Пупсік/я/я сама/це я, побажання та подарунок. Перевірка ігнорує регістр, пробіли й пунктуацію.

Сторінки незалежні. Перезавантаження повертає питання. Підтримано reduced motion. Це гра, а не захист від людини, яка вже має QR.

## Публікація

Settings → Pages → Deploy from a branch → main → / (root).

## Відео та подарунок

Готовий `varya_birthday_heartfelt_stable.mp4` із попереднього чату не доступний локально. Поки відео не додано, Level 2 пропонує подивитись його разом. Подарунок відкриває безпечний локальний reveal. Для зміни цих налаштувань потрібен локальний вихідний комплект: config.js → videoUrl (MP4 шлях або HTTPS), giftUrl (HTTPS); потім перешифруй HTML тим самим ключем з приватного QR з новим випадковим IV. Не публікуй ключі.

## Друк

Приватний комплект містить SVG і PNG високої якості та qr-print.html для A4. Друкуй у масштабі 100%, не обрізай біле поле. Перевір камерою телефона перед врученням.
