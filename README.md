# Для Варі ❤️

Оновлений birthday quest: чотири зашифровані рівні в існуючому varya-day. Кожен QR містить окремий ключ у URL fragment; ключ не надсилається серверу. QR й повні посилання зберігай приватно — не коміть їх у публічний репозиторій.

Level 1: 1370 днів. Level 2: пряме відео. Level 3: «Куди?» та boarding pass на 18 OCT 2026, 16:30, координати 35.3222446,25.3918038, Navigate. Level 4: прямий PDF-подарунок та побажання. Перевірка ігнорує регістр, пробіли й пунктуацію.

Сторінки незалежні. Перезавантаження повертає питання. Підтримано reduced motion. Це гра, а не захист від людини, яка вже має QR.

## Публікація

Settings → Pages → Deploy from a branch → main → / (root).

## Відео та подарунок

QR 02 одразу відкриває відео Varya.mp4 (мобільна версія H.264/AAC 540×960, близько 14 MB). Телефон може вимагати натиснути ▶ для звуку. QR 04 одразу відкриває HIGH HEELS DANCE CAMP та зашифрований PDF-квиток із переглядом і завантаженням. Відео та PDF захищені AES-GCM ключами відповідних QR. Ключі та розшифровані медіа не публікуються в репозиторії. QR 01/03 зберігають загадки. QR-посилання не змінилися.

## Друк

Приватний комплект містить SVG і PNG високої якості та qr-print.html для A4. Друкуй у масштабі 100%, не обрізай біле поле. Перевір камерою телефона перед врученням.
